Dock Float Lab

Standalone design harness for the delivery "+pts" floater column. Not part of the game build — no build step, no imports; this file carries its own copies of the real math (FloatText, drawText, drawPoly, glowStroke, the dock octagon, the offload point formula). Any knob change restarts the run, so the minimum-separation number below always describes one clean run under the settings you are looking at.

Anchor

Ship mode reproduces today's shipped behaviour: origin = ship.y − DELIVERY_FLOAT_DY (22). The mock ship circles the dock at radius 60 — a delivering ship has to stay inside dock.radius + 10, so it can only ever smear the column, not leave it.

The offload timer is reset to a flat interval and decremented by whole frames with no remainder carried, so the realised cadence is a whole number of frames. At 60Hz, 0.05 costs four frames (0.0667s), not three — the shipped column's true spacing is 10.7px where the CS026 comment records the ideal 8.0. Both numbers are in the readout below. The game does exactly this, in exactly this way; the lab copies it rather than idealising it.

Points are the real formula: DOCK_BASE_SCORE + DOCK_BONUS_STEP × (n−1) = +50 … +625 at 24. SALVAGE BONUS fires at canister 8, MAX HAUL at canister 24 (CARGO_CAP_MAX) — both at dock.y − 22 with the FloatText defaults (rise 30, life 1.1), i.e. dock-anchored, exactly as shipped. Set canisterCount to 24 to see both.

Both numbers are run-minimums of the vertical gap between two live floaters, measured in y only — so in ship mode two floaters far apart in x still count as close. That is deliberate: a column that only separates because the ship wandered is not separated.

Why two numbers. The specced "any two live floaters" figure is the second one, and no model can improve it: SALVAGE BONUS / MAX HAUL are born at dock.y − 22 with FloatText's defaults, so they climb 30 × 1.1 = 33px and top out at dock.y − 55 — straight up through a dock anchor set below that, whatever the column is doing. The lever for that collision is anchorFrac, not the model. Measured, all-floaters minimum at the defaults:

frac  anchor    A      B      C
0.50   44.0    0.2    0.3    0.0
0.625  55.0    3.2    5.2    1.0
0.70   61.6    9.8   11.8    7.6
0.75   66.0   10.7   16.2   12.0
0.80   70.4   10.7   20.0   16.4
1.00   88.0   10.7   20.0   32.0

Crossing stops above 0.625 (55/88); a clear glyph of air needs ~0.81 ((55+16)/88), where each model saturates at its own column figure and the milestone stops being the binding pair. The first readout isolates the delivery column, which is what tells A, B and C apart.
