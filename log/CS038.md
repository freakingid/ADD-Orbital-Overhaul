## P1 — Credits screen

A fifth `MENU_OPTIONS` row (`"Credits"`, before `"Back"`), driving a read-only screen off a new
`CREDITS_ROWS` data table (`head`/`text`/`link`/`gap` rows) — a later credit is a one-row edit, never
a render change. `menuCredits`/`drawCredits` follow the `menuHighScores`/`drawHighScores` single-
parent template; up/down move the cursor between `link` rows only, and the scroll is derived from
the cursor on every nav press and draw, with the first/last link pinned to the two scroll extremes so
the header block and the SATELLITE SILHOUETTES/LICENSE tail are reachable. `openExternal(url)` is the
build's first and only `window.open`, always `(url, "_blank", "noopener")` — its status line is
worded conditionally, since `noopener` makes `window.open`'s return value indistinguishable between
"opened" and "blocked." Every URL draws in full under its label regardless of selection, so a blocked
popup (itch.io's sandboxed iframe fails silently) still leaves the address on screen. The satellite
block is explicitly an inspiration list, not an attribution list — "No assets were used." is the
load-bearing line, since the twelve silhouettes are original code-authored art (§2.4). Registry
unchanged at 115 (C4 caught the spec's own registry count as wrong — 61 literal rows + 18×3, not 60).

## P2 — `tools/lowhp-glow-lab.html`

The low-hull glow measurement instrument for GATE A. `orbital-overhaul.html` untouched by this phase.
The glow is a PORT-ME BLOCK copied byte-for-byte out of `drawHUD()`, driven from sliders over a
seeded busy-frame backdrop (HULL/CARGO rings + powerup rows at real coordinates, painted on

edge vignette, edge bars, corners-with-occupied-corners-attenuated — measured by `getImageData` at
eight edge probes plus a centre control, headlined by worst-probe WCAG glow:background contrast.

## P3 — Telemetry capture becomes opt-in; voice repeat suppression mechanism 1

Two independent pieces landed in one commit. **Telemetry:** a new `sessionSwitch: true` flag on a
`DEBUG_VARS` entry — `telemetryCapture`'s first use — omits the row from `saveSettings`'s persisted
blob, skips it in `loadSettings`'s restore loop, and exempts it from the master "Overrides Applied"
toggle in both `applyDebug` and `rebuildDebug`, so a launch can never revive a stale capture-on state
from a prior session. `Telemetry.tick()` gates on `DEBUG.telemetryCapture` alone; the export path
(`read()`, `telemetryExportRows()`, "Copy telemetry log") is deliberately ungated, so a captured log
stays reachable the morning after with capture switched back off. Registry 115 → 116.

## P4 — Voice repeat suppression, both mechanisms

Playtest gate B's motivating finding: `cargo_full` and `chain_lost` have exactly one line each, are
both `VOICE_CRITICAL`, and both fire more often since CS037 P5's full-tow-release change — so the
no-repeat picker (mechanism 1, landed with P3 above) can't help them. **Mechanism 2 — the entry-gate
repeat window**, in `_emit()`: an event that passed the gate within `voiceRepeatGap(event)`
(`VOICE_REPEAT_GAP` 12s ordinary / `VOICE_REPEAT_GAP_CRITICAL` 20s for `VOICE_CRITICAL` events) is
**dropped at the top of the gate, before the busy/cooldown branches — including a critical one, which
does not park.** Parking would replay the identical line seconds later, exactly what this exists to
stop. `level` is exempt (`VOICE_REPEAT_EXEMPT`) since it carries data (a different number each
firing). The window runs on `AudioSys.now()`, never game time, and takes no `dt` — the same no-TTL
rule the park queue already followed. `VoiceSys.reset()` clears both `lastLine` (mechanism 1) and
`lastSpoke` (mechanism 2) at the top of every run.
