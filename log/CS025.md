## Known issues

- **CS025 P4 — `VOICE_STILL_TRUE.cargo_full` USES `>=` WHILE ITS TRIGGER SITE USES `===`, AND THAT IS CORRECT.** The trigger is `if (game.chain.length === game.cargoMax) VoiceSys.say("cargo_full")` — an exact equality, because it fires on the pickup where the chain *becomes* full. The drain predicate is `game.chain.length >= game.cargoMax`, because per `PLANNED-FEATURES-CS025.md` §4.4(d) it mirrors **the pickup gate** (`const cargoFull = game.chain.length >= game.cargoMax`), which is the thing that is still true a few frames later.
